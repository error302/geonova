## 2025-02-27 - Sanitize SVG outputs across all components
**Vulnerability:** XSS vulnerability through SVG strings generated and dynamically injected into the DOM using `dangerouslySetInnerHTML`. Even though backend/generator code escaped some fields (`escapeXml`), it is not sufficient since SVG `<text>` fields or missing sanitization rules can still execute payloads in different ways.
**Learning:** Found multiple usages of `dangerouslySetInnerHTML` rendering un-sanitized SVG. Despite having a `sanitizeHtml` utility using DOMPurify that explicitly noted its safety for `dangerouslySetInnerHTML`, it wasn't being consistently applied (MutationPlan, DeedPlan, Beacon Reference Tool), and it lacked full support for SVG tags.
**Prevention:** Ensure DOMPurify configuration is extended to support essential SVG tags and attributes (`line`, `text`, `rect`, `circle`, `g`, `points`, etc.). Enforce the usage of a centralized sanitization wrapper (like `sanitizeHtml`) around *all* dynamically constructed SVGs when injected into React using `dangerouslySetInnerHTML`.
