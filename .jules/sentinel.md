## 2026-08-30 - Fix XSS vulnerabilities in SVG rendering
**Vulnerability:** DOMPurify was used to sanitize SVGs using `ALLOWED_TAGS` and `ALLOWED_ATTR`, which restricted standard drawing elements. This led to XSS vulnerabilities not being properly sanitized in mutation plans and deed plans where `dangerouslySetInnerHTML` was used without `sanitizeHtml`. Further, the `sanitizeHtml` was unnecessarily wrapping static safe code which could cause React hydration mismatches.
**Learning:** For rendering SVGs safely, explicitly relying on `USE_PROFILES: { html: true, svg: true }` while defining `FORBID_TAGS` (e.g. `image`, `foreignObject`) and `FORBID_ATTR` (`href`, `xlink:href`) provides a robust defense without stripping essential visual aspects. Static/trusted server rendered enums should not be sanitized during hydration.
**Prevention:** Always verify `dangerouslySetInnerHTML` includes sanitization when dealing with user generated content and use robust configuration mechanisms provided by DOMPurify such as profiles.
