## 2024-05-18 - [HIGH] XSS Vulnerability in Dynamically Generated SVG Previews
 **Vulnerability:** DOMPurify was configured with explicit `ALLOWED_TAGS` and `ALLOWED_ATTR` that did not comprehensively support all required SVG capabilities, preventing the sanitization of dynamically generated surveyor SVG plans when rendered via `dangerouslySetInnerHTML` due to functional breakage.
 **Learning:** SVG manipulation and rendering can bypass strict DOMPurify filters. Using `dangerouslySetInnerHTML` on arbitrary SVG output without proper sanitization leads to XSS if the SVG contains an injected `<script>` tag or user data within its elements (e.g. text/metadata nodes like project names or numbers).
 **Prevention:** For DOMPurify, use `USE_PROFILES: { html: true, svg: true }` when working with SVGs rather than a brittle hardcoded list of tags/attributes. Always pass user-influenced SVG content through this pre-configured instance before embedding. Do not use this sanitization layer for static/trusted SVGs which might trigger React hydration mismatches.
