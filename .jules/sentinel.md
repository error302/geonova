## 2025-02-27 - Configure DOMPurify to allow safe SVG attributes securely
**Vulnerability:** The `sanitizeHtml` wrapper configured DOMPurify with an exact allowlist of SVG tags and attributes to prevent XSS. However, manual maintenance of this list is error-prone and some elements needed for rendering (like `<svg>`) might be stripped out, leading to functional regressions. Specifically, the manual `ALLOWED_TAGS` and `ALLOWED_ATTR` configuration bypassed the safety built into DOMPurify's profiles and created a brittle system.
**Learning:** Using DOMPurify's built-in `USE_PROFILES: { html: true, svg: true }` combined with specific blocklists (`FORBID_TAGS: ['image', 'foreignObject']`, `FORBID_ATTR: ['href', 'xlink:href']`) is far more secure and less prone to regressions than a manually maintained allowlist.
**Prevention:** When dealing with dynamic HTML or SVGs, always prefer established configuration profiles in sanitization libraries (like DOMPurify) over maintaining manual, brittle lists, and explicitly forbid known XSS/SSRF vectors such as `image`, `foreignObject`, and `href`.
