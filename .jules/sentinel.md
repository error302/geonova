## 2024-08-11 - [Missing Standard SVG tags whitelisting in DOMPurify causing XSS Vulnerability]
**Vulnerability:** XSS vulnerabilities in dynamically generated SVG content (`DeedPlanGenerator.tsx` and `MutationPlanGenerator.tsx`) due to `sanitizeHtml` missing crucial standard SVG tags (`path`, `g`, `rect`, `circle`, `line`, `text`, etc.) in its `ALLOWED_TAGS` leading to developers bypassing the wrapper entirely with `dangerouslySetInnerHTML`.
**Learning:** `DOMPurify` requires explicitly allowing all standard SVG tags and attributes in order to properly render an SVG when using `dangerouslySetInnerHTML`. If legitimate SVG tags are stripped, developers are tempted to omit sanitization, creating an XSS vulnerability when SVG content is user-supplied or user-influenced.
**Prevention:** Always ensure standard SVG tags and their stylistic attributes are fully whitelisted in the application's global `sanitizeHtml` utility so developers can securely render dynamic SVGs without breaking layout or omitting sanitization.
