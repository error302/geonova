## 2025-02-28 - XSS Vulnerability in SVG Rendering
**Vulnerability:** User-provided inputs rendered in SVG contents were dynamically set using `dangerouslySetInnerHTML` without proper HTML sanitization in Deed Plan and Mutation Plan generators, presenting an XSS vulnerability (e.g. `dangerouslySetInnerHTML={{ __html: output.svg }}`).
**Learning:** `DOMPurify` requires special configurations (`USE_PROFILES: { html: true, svg: true }`) to allow standard SVG attributes (like `cx`, `cy`, `r`, `stroke`, `fill`, etc.) without being overly permissive. Manually specifying `ALLOWED_TAGS` and `ALLOWED_ATTR` was fragile and frequently resulted in broken SVGs or potential functional regressions while omitting essential SVG tags.
**Prevention:** Always use `sanitizeHtml` from `@/lib/security/sanitize` when using `dangerouslySetInnerHTML` to render SVGs and ensure `DOMPurify` is properly configured using `USE_PROFILES: { html: true, svg: true }` instead of manual attribute/tag whitelisting.
